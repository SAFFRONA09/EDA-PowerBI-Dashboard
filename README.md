# EDA-PowerBI-Dashboard
This project focuses on Exploratory Data Analysis (EDA), data cleaning, statistical analysis, and interactive dashboard development using Microsoft Excel and Power BI.The objective of the project was to transform raw business data into meaningful insights through data preprocessing, KPI analysis, and visualization techniques.
Tools & Technologies Used:
  Microsoft Excel,
  Power BI,
  Data Visualization,
  Exploratory Data Analysis (EDA).
